HOW TO TEST
================================================================================

1. ENSURE SERVICES ARE RUNNING:
   - Laravel API: http://localhost:8000
   - Mobile App: http://localhost:8081
   - Admin: http://localhost:3000

2. TEST GUEST MAP:
   - Open http://localhost:8081
   - Navigate to "Explore" tab
   - Click "Map" tab
   - You should see:
     * Interactive OpenStreetMap centered on Siquijor
     * Location markers with colors
     * Filter buttons
     * "📍" button for current location

3. TEST MARKER INTERACTION:
   - Click any marker
   - Bottom card should appear with:
     * Location name
     * Category
     * Description
     * Address
     * "View Details" and "Book" buttons
   - Click "View Details" → navigates to details page
   - Click "Book" → navigates to booking page

4. TEST LOCATION PERMISSION:
   - Click "📍" button
   - Grant permission when prompted
   - Map centers on your location
   - Blue marker shows your position

5. TEST FILTERS:
   - Click each filter: All, Tour Guides, Tourist Spots, Resorts, Food, Rentals
   - Map updates to show only selected category

6. TEST ADMIN LOCATION PICKER:
   - Open http://localhost:3000/admin/spots
   - Click "Add spot"
   - You should see location picker map
   - Click map → marker appears, coordinates display
   - Drag marker → coordinates update
   - Fill form and submit → spot created with location
